# Legal corpus — CA-PILOT-005

本包共 43 条检索条目。`corpus.jsonl` 为正文，`index.json` 为同内容元数据，`raw/` 保留原始输入快照以及明确命名的新检索记录。`verification.json` 记录本次实际完成的核验范围。

已核验所用关键历史核心条文和要件；不声明完整历史法典／CALJIC卷册复原。`effective` 用于可用性截止判断，其含义由 `effective_basis` 明示：可能是确切有效日期、判决日期，或保守的已证实可用日期，不应统一当作立法生效日。`retrieved_at` 是来源抓取日期，不是法律有效日期。

`canonical_id` 标识同一规则的来源别名。特别是 `L-EVID1101` 与 `L_EVID_1101` 的相同(a)-(b)核心均在1997年已有效，不应因ID或网页日期不同把其中一个判为未来法。原始教师抽取记录里的旧元数据原样保留供追溯，运行采用 corpus/index 的修订字段。

新加入的判例文件是原判网页的短摘录、检索定位及研究摘要，有真实URL、抓取日期和字节／正文SHA256；它们不是完整原判HTML。使用的是原判正文而非网站的自动摘要。中文陪审指示位于 `../world/jury_instructions.json`，逐项列明支持法源与改写范围。
