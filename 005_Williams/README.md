## 改了什么

原始19条锚点全部保留并带原文定位，新增170条authored事实，共189条、32份文书；初始只披露9份，占28.125%。每条事实有fact_id和来源类别，角色卡按个人知识、条件追问及轮次控制。世界另有表格、签名、查询、资质、监管链或第三方记录的缺口，既有有利线索，也有不能消除的不利材料。

本题核心是：登记义务的基础、进入辖区与住所变化的起算、五个工作日、实际知情与故意。原型的不利事实——知道登记要求、未完成登记及未联系假释官——保留；声称尝试登记、旅馆威胁与独立印证分开。

世界中的补写细节预先写好。开示、第三方传票和现场调查不会临场创造新事实；请求具体且权限吻合才返回相应文件。过宽或无关请求可能没有结果。每次动作实际扣小时，庭前总额度36小时、72个动作、费用3000模拟单位。谨慎专家费用2400，便宜专家费用800；专家仅能读律师实际交付的材料，意见可能不利。庭内异议窗口免费，非法动作不扣额度。

四份必交工作文件已在委托中明确：case_timeline.csv、evidence_register.csv、pretrial_plan.md、examination_outline.md；按新资料更新并保留版本，工作文件不会自动变成证据。

## 三轮及真实的新信息

第一轮：准备、证据动议、证人出庭与交叉询问、基于当时记录的最终裁定。轮间控方补交新材料，律师可以核读、调查和调整文件。

第二轮：控方及辩方开场、控方主询问/辩方交叉、控方举证后1118.1申请、辩方举证与控方交叉。每段控方发言、提问和回答都有统一实时窗口；候选看到实际台词，不知道未来剧本或陷阱编号。迟交救济准许后有真实补充准备动作，再回原举证阶段。异议记录目标事件、真实窗口和及时性；窗口外动作不能取得及时救济的满分。

第三轮：定向补充证言、必要的申请更新、指示会议、控方结案→辩方结案→控方反驳→宣读实际准许指示→六名独立陪审员逐罪投票。第二轮准入记录和用途限制继续有效；程序听证记录不会自动进入陪审团。无罪动议逐罪裁定：全案获准即依法终结，部分获准只就余罪继续审理及陪审投票。第二轮补充告知材料及第三轮代理人说明会改变准备范围。期限的手写提醒与法定工作日计算分开；机关查询的无登记结果不等于没有接触过窗口。

披露、已读、已提交、已采纳、排除、限定用途分别记载。事实约束不只检查编号存在，还验证自然语言陈述是否由允许事实支持。陪审团使用逐句证据单元；被排除的事实不能通过原始锚点绕过排除，其他合法内容及用途限制仍分别保留。

从项目根运行`bash setup.sh`、`bash run_005.sh offline`。自动密钥提示及后台启动的完整步骤见[项目根README](../README.md)。默认`bash run_005.sh`启动本题流水线；`bash run_005.sh status`查询。
