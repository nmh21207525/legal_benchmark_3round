# CA-PILOT-005｜辩护律师任务

案件：迁居、登记告知与五个工作日的计算。你代理被告A，应对以下原案实体指控。

- C01：故意违反性犯罪者登记义务（Penal Code §290(a)(1)(A), former version; felony registration failure）

事件日期范围：2006-05-24至2006-06-03；法律适用基准：2006-06-03；检索截止：2026-10-02。

## 三轮任务

1. 第一轮：核对起诉范围、登记告知、材料来源和既往事实的用途；可向B、C询问已记载基础，提出申请与异议。待裁证据和动议转入r1_ruling完成裁定。

2. 第二轮：分别询问B、C，按A的自愿选择决定其是否作证，比较登记告知、住所变化、尝试登记和搬离解释；逐项处理证据的采纳和用途。

3. 第三轮：对第二轮已出现的矛盾或缺口作定向补充询问，再围绕C01的期限、知情、故意与举证责任作结案论证，由法官下达指示并记录裁决。

## 材料与提交

M01—M08均在准备阶段向双方律师和法官开放，初始为已披露、未采纳；M05没有延后披露要求。A的绑架及被拒登记说法保持为其本人主张。不得创作亲属、接待人员、绑架者的证词或新文件。此前犯罪仅按获准用途使用。本题不评量刑或已省略的上诉争点。

正文保留未知、争议和转述。所有M材料均为原判决的来源摘要，原始案卷未随来源取得的部分不补造。引用M编号及段落、L法律编号，提交申请、问答、异议、裁定引用和结案论证。相关性异议填写公开charge_id及relevance_explanation，隐藏评分争点由评分端映射。
