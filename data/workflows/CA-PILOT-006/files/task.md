# CA-PILOT-006｜辩护律师任务

案件：酒驾致伤中的PAS筛查与后续抽血。你代理被告A，应对以下原案实体指控。

- C01：酒精影响下驾驶并致他人伤害（Vehicle Code §23153(a)）
- C02：血液酒精含量0.08%以上驾驶并致他人伤害（Vehicle Code §23153(b)）

事件日期范围：2000-08-16至2000-08-16；法律适用基准：2000-08-16；检索截止：2026-10-02。

## 三轮任务

1. 第一轮：围绕已有PAS之后无令状抽血提出抑制申请、回应和基础询问；仅使用抑制阶段可见资料。待裁证据和动议带入r1_ruling并形成带段落、用途和理由的裁定。

2. 第二轮：依裁定询问B；对事故、伤害及毒理数值采用获准的来源摘要，A自愿作证时才询问其已有经历。此轮开放M06的正式审判记载，讨论其实体用途。

3. 第三轮：就告知、测试基础、浓度证明和正式审判新增记载进行定向补充询问及双方结案论证；分别判断C01、C02。第二轮已采纳记录继续有效，法官最后下达指示。

## 材料与提交

M01—M05、M07—M08在准备阶段向双方律师及法官开放，M05初始已披露。M06初始未披露，在r2_examination由可信编排服务记录stage_release:M06后同时开放给双方律师和法官；其属于原案正式审判才出现的记载，不能进入第一轮裁定基础。毒理人员仅为记录角色，不实时答问；0.12%是判决转述的结论，原始报告未取得。不得补写时间、仪器、校准、伤情或饮酒数据。本题只评两项实体罪，不执行量刑和加重指控裁决。

正文保留未知、争议和转述。所有M材料均为原判决的来源摘要，原始案卷未随来源取得的部分不补造。引用M编号及段落、L法律编号，提交申请、问答、异议、裁定引用和结案论证。相关性异议填写公开charge_id及relevance_explanation，隐藏评分争点由评分端映射。

A是否作证由其自愿选择，保持沉默不能作为有罪证据。披露不等于采纳；第一轮程序讨论不自动成为陪审团证据，第二轮已采纳记录在第三轮继续保留，后续排除、用途限制及划除同样继续有效。

# CA-PILOT-006 全流程辩护任务（三轮庭审）

你是被评测的辩护律师。先完成可观察的庭前文件处理和准备，再参加本案规定的三轮庭审。
文件是所给材料的来源约束摘要及所给法律摘录，不是未取得的原始报告、录音、录像或逐字证言。保留M段落编号。

1. 用list_files/read_document实际读取所需文件；用search_case/search_law/search_record进行授权本地检索。检索不访问互联网，不得声称已联网或取得工具未返回的内容。
2. 区分已知、转述、推断、争议和未知，形成具体准备方案。用request_investigation或request_examination向资料核验服务提出明确问题及目的；服务实际查询冻结案包并返回报告文件和可用性状态，不联系真实机构，不保证发现新证据。not_available_in_supplied_record仅表示本包没有原件，不表示历史上不存在。可在允许的准备或轮间阶段向A私下咨询；对方按自己的来源知识范围回答，问答将单独保存，不能补造资料。
3. 用write_artifact实际保存以下四份可打开的文件，内容由你生成，不要只写空模板：
   - case_timeline.csv：事件、日期或顺序、未知处、M段落来源。
   - evidence_register.csv：材料及段落、来源性质、披露及采纳状态、潜在用途与缺口。
   - pretrial_plan.md：分项指控、关键问题、法源与事实、行动优先级、真实调查反馈和条件替代方案。
   - examination_outline.md：可询问对象、具体问题、目的与出处、未知答复的后续处理。
   调查反馈及各轮裁定后可以更新，文件版本与事件会保存；也可保存允许的补充说明。
4. 第一轮处理程序、证据和裁定；第二轮完成举证询问；第三轮对既有记录作补充询问、结案、法律指示和分项裁决。具体动作和角色以当前阶段授权为准。
5. 庭审继续用既有M段落和L法律编号。计划不是已执行行动，调查摘要不是新历史证据，披露不是采纳。角色按权限和实际裁定接收内容，私有准备不会自动送交陪审团。第二轮获准记录继续保留到第三轮，限制、排除及划除仍有效。

M06仅由可信程序在指定第二轮阶段完成开放事件后同步披露；角色知识同样受该事件限制。本约定不提前提供其内容，也不允许倒改第一轮裁定。毒理结论角色仅为记录角色，不生成实验室现场问答；R_SOURCE_RECORD只能呈现获准段落。

完成情况看实际记录、问答、工具返回和文件内容，不按工具次数、文件字数、是否发现有利证据或最终胜负奖励。允许其他有来源支撑的辩护路径。独立评分标准不提供给庭审角色。
