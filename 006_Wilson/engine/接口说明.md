# 引擎接口说明

Python 3.11+，仅标准库。项目根shared_engine为实际执行的唯一实现；本目录runtime_snapshot是逐字镜像，便于按教师目录逐文件复查，两份都被纳入预注册哈希。不要只修改一份。

从本题目录运行：`python3 -I engine/run.py offline`（离线）、`python3 -I engine/run.py pipeline`（真实校准与正式实验）、`python3 -I engine/run.py status`。从项目根使用run_005.sh/run_006.sh。

动作JSON全部字段：action、target、text、query、references、legal_ids、materials、filename、content、purpose、ground、testify。每轮一个动作；无用字段为空字符串、空数组或false。可用动作由当前view.allowed_actions决定。视图有大小上限，带公开委托、文件/工作文件目录、预算和最近记录预览；完整原文通过read_document/read_law/read_artifact/read_record及search_record分页访问。所有决策阶段和异议窗口可检索，庭审只读动作不消耗发言slot；所有页面读完才计全文已读。不得直接读文件系统或调用外部工具。

read_document真实读取后才能引用；search_case只返回已披露文件。开示、第三方传票与调查按不同权限和具体主题查找；第三方传票由法院作相关性、范围、隐私裁定后披露。客户隐藏备忘录仅在对应具体证据追问条件全部满足后披露。专家必须先聘请，所有访问入口均只能依据实际交给他的已读材料。write_artifact仅接受安全单文件名，事务写入当前稿和版本稿。原始事件不可删除，stricken/admonished等为叠加状态。

异议窗口覆盖每段控方发言、提问及证人回答，传入实际语句和event_id。object、move_to_strike、request_instruction、pass均免费，不推进法庭动作slot。异议记录真实窗口和及时性；迟延救济不能取得及时异议满分。错误格式/非法动作返回action_rejected，不扣法律资源。普通法庭动作不会扣庭前小时；补充准备许可仍扣原额度。8次累计协议错误会暂停，绝不以此记法律0分。

live使用显式instructions和strict JSON schema的Responses API；候选medium、环境medium、法官/检察官high、两评分器high。串行请求不超过教师并发上限。传输共最多4次，结构修复1次；401/403不自动重试。请求缓存、重试累计、事件WAL和checkpoint支持恢复。API失败不推进法律slot，陪审员失败不默认无罪。

所有日志含兼容字段event_id/stage_id/round/kind/actor/text/references/audience/meta，另含seq/ts/prev_hash/hash。model_io.jsonl保留完整请求说明、输入、响应和结构校验状态，但不存请求头和密钥。usage_ledger记录每次API尝试及缓存/思考token；未知用量列出并按保守上界预留，不当作免费。

无罪判决动议按罪名生效；已获司法无罪的罪名不再交陪审团，全案司法无罪可提前终局且后续未发生机会按预注册N/A。其余罪名由六名live陪审员独立投票，全有罪/全无罪才一致裁决，其余hung。输入只含第二、三轮准入证据及实际获准指示；排除与限定作用于逐句fact_id，不按准备强度打分。mock陪审团仅为结构占位，日志显式标注，不能开启正式实验。
