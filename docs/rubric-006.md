# CA-PILOT-006：三轮庭审评分说明

**48 项，每项 0／1／2 分，总分 96 分。** 四个候选律师使用同一份运行前冻结标准，最终百分比为 `100 × 实得分 / 96`。评价律师的行为和产物，不以是否胜诉决定分数。

本标准依据题包材料、所给历史法律摘录、角色权限和可用工具预先编写。`approved: true` 表示用户授权此次实验使用，不代表独立人工法律审核；这是 AI 辅助编写版本，未冒充已经做过真实开发验收。完整锚点见 `rubrics/drafts/CA-PILOT-006.json`；运行使用其冻结副本。

## 怎样给分

- **0 分**：完整记录未展示本项要求，或出现该项明确的重大错误；理由须区分“未展示”和“错误”。
- **1 分**：有记录支持的部分完成，达到该项的部分完成锚点。
- **2 分**：满足该项必要条件或有来源的等效路线。只有计划、未执行的请求、自动产生的环境动作或空文件不等于完成。
- 按真实行动和内容评价，不按字数、工具数量、问答轮数或文件数量奖励。允许一次合规行动内清楚组合多个问题，不能仅因合并提问扣分。
- 同一记录可以支持不同独立能力；但一段笼统话语不能自动满足全部相关项，一处遗漏也不能不加分析地在各项重复扣分。
- 没有预设低于 80 的目标或模型排名。合理高分不因分数高而被压低。

## 本题必须保留的边界

1. **以所给历史摘录为基准。** 不引入后来的法律规则代替 2000-08-16 的题设基准，也不能把原型判决结论当标准答案。历史版本与摘要的来源限制保留在交付说明。
2. **M06／F10 延迟开放。** 只能在第二轮 `r2_examination` 且可信 `stage_release:M06` 后使用；不要求律师提前知道内容，不能把第三轮知道的事实倒填进第一轮。披露仍不等于采纳。
3. **未知不等于否定。** 没有原始报告、时间、设备或医疗资料，不等于原案没有该资料、检测必错或伤害未发生。0.09 与 0.12 不能被擅自用于逆推饮酒或驾驶时浓度。
4. **尊重角色能力。** B 不是碰撞目击者；A 只回答已给出的 PAS 告知和抽血态度，作证由其自愿选择；毒理及摘要角色是 `record_only`，不能要求生成实验室现场问答。
5. **依实际机会评价。** 请求未获法官同意、A不作证、工具返回“本包无原件”，不自动扣至0；按请求质量、真实反馈和合理替代路径评价。A尚未被请求出庭时，可以有记录依据地选择不申请其出庭，但不能冒称A已经拒绝；第三轮已有问题均澄清或只剩来源外未知时，可以说明依据而不重复追问。法官指示和陪审团裁决本身不算律师表现，律师可在结案等允许阶段提出自己的指示立场。
6. **固定分母并披露观察限制。** 技术或编排原因使事项确无观察机会时，按固定清单记未展示并写 `observation_limit`，不写成律师必须完成不可能任务。严重环境缺陷应单列，不能靠删除评分项掩盖。

## 输出与复核

独立评分器读取完整庭前过程、工具反馈、实际文件和三轮庭审，一次评价全部项目；旧分数与最终模拟胜负不用于打分。结果包含逐项分数、理由、事件或文件引用及观察限制。基本格式错误会按统一累计额度重试；引用复核提示保留供检查，不自动修改模型分数。

本版本没有读过本次四个候选模型的运行输出。正式运行后若要改标准，需新版本、重新冻结，并对同一比较中的所有候选记录统一重评；不能为某个候选单独调整门槛。
