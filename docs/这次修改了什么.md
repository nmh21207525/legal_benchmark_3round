# 005、006这次修改了什么

原始数据自带的是判决摘要中的案件事实锚点：005有19条、006有16条。为实现教师要求的调查空间，后续预先构建了文书、访谈、日志等模拟细节；分别标为authored，不能称作原案真实卷宗。原始材料及定位完整留档，不向候选开放。

| 原始交付／此前实现 | 本次实现 |
|---|---|
| 旧自建工程005为46项／92分、006为48项／96分，调查空间较小 | 每题32文书，初始9份；005共189事实、006共182，60项预注册评分 |
| 旧式四模型各一次 | 每题GPT两次、Seed两次；环境及双评分模型、effort按教师要求固定 |
| 三轮程序骨架 | 保留三轮，增加轮间披露、资源取舍、真实异议及证据效果、定向补充、实际指示 |
| 可能仅靠`window=true`判断异议 | 记录目标事件、真实窗口、及时性与事件距离，迟异议不能取得及时救济满分 |
| 无罪动议可能退化为一般动议 | 逐罪裁定；全案获准依法终结，部分获准只审余罪，结局评分及未到达机会N/A一致 |
| 摘要或编号容易替代完整阅读 | 文书与法源分页提供；全部页读完才算完整阅读，重复法源按canonical_id去重 |
| 客户材料追问判断过宽 | 以实际针对具体事实的追问与核对记录评分，泛问不算完成 |
| 历史法律日期、版本及指示有待澄清 | 005扩为43、006扩为47检索条目；补关键旧法／判例／CALJIC依据，统一1101别名及截止标志 |
| 质量证据过长可能丢失尾部 | 全部证据带路径、偏移、来源哈希分块，逐层合并后双评分；分歧和严重错误单列 |
| 只有零散分数与回放 | 各评分器、双评分均值、重复均值范围、一致率、分歧、预算及旧新对照，HTML含实际文件正文及版本 |
| 需要手动拼接交付目录 | 默认后台流水线完成后自动严格ZIP；支持安全stop／resume、单题export和两题export-all |
| 未完成也可能被误称正式包 | 严格检验真实校准冻结、4场live双评分、轨迹／配置／评分／预算；部分材料明确partial |

当前实际运行记录与分数见各题`RESULTS.md`，工程和解压测试见[verification_report.json](verification_report.json)、[extraction_verification.json](extraction_verification.json)。初始源码附离线演练，离线占位裁决与机械分不是真实模型法律成绩。

法律核验采用已有官方快照、原型判决历史引文和新增原判依据；具体已核实内容、保守日期、摘要保存方式及尚未覆盖范围以[law_verification.md](law_verification.md)为准。没有声称复原完整历史法典／指示册，也没有声称已完成执业律师全面人工复核。
