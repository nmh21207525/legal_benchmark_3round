验证命令：

```bash
python tools/verify_legal_sources_v2.py
```

该只读检查核对所有原始文件与正文SHA256、index一致性、别名日期、截止标志、指示中的罪名与法源引用。`tools/revise_legal_corpus_v2.py`可在同一源包上离线、幂等重建这次数据修改；它同时重新检查关键选文与原始资料。重建会改变后续预注册输入摘要，必须先重建，再重新冻结实验；不要在已经开始的正式实验中修改法源。
